# 我的常用网站推荐: 3必导航 必属精品，必用免费，必然清爽


这里记录了一些我日常使用和喜爱的优质网站与工具，涵盖搜索、资讯、AI、社交、阅读及影音等领域。

## 搜索引擎
* [Google](https://www.google.com) - 全球最大的搜索引擎，精准高效。
* [Yandex](https://yandex.com) - 俄罗斯主流搜索引擎，在搜图及特定资源检索上表现卓越。

## 新闻资讯
* [今日热榜](https://newsnow.busiyi.world/) - 一站式聚合各大平台热搜与新闻头条。

## 人工智能
* [Gemini](https://gemini.google.com) - Google 推出的多模态 AI 助手。

## 社交平台
* [X (Twitter)](https://x.com) - 全球实时资讯与社交动态。
* [Reddit](https://www.reddit.com) - 涵盖各类兴趣主题的海外网络社区。
* [Facebook](https://www.facebook.com) - 全球性社交网络服务平台。

## 小说阅读
* [69书吧](https://www.69shuba.com) - 丰富的在线小说资源阅读平台。
* [速读谷](https://www.sudugu.org) - 便捷的小说在线阅读网站。

## 在线视频
* [YouTube (油管)](https://www.youtube.com) - 全球最大的视频分享与观看平台。
* [注视影视](https://gaze.red/) - 优质的高清影视在线观影平台。

## 装机必备
* [火绒安全](https://www.huorong.cn) - 轻巧无打扰、专注于防护的国产杀毒安全软件。
* [Everything](https://www.voidtools.com) - Windows 系统下速度极快的本地文件搜索工具。
